# PradhanMantri Elections Game

Play: https://pradhanmantrielectionsgame.com/

A turn-based election strategy game on an interactive map of India. Free, no
ads, no account, no data collection. Runs in any modern phone browser.

This repo holds the built site only — it's generated from a private source
repo and pushed here as-is. Don't hand-edit anything: the next deploy
overwrites it.
