Booth Ink · design review

The ballot card

A trading-card treatment for the politician-select screen — collectible-card structure (art window, stat masthead, attack box) built from this game's own vocabulary: ink, stamps, ballots, brass. Tap a manifesto plank to see it open.

Design notes

Why ink-and-brass, not holo-foil. A literal Pokémon card reads as a costume the game didn't earn. This keeps the trading-card structure — art window, stat header, attack box, set index — but builds it from Booth Ink's own materials: a warm ballot-paper card stock, a brass seal instead of a glossy energy-type icon, a red wax-seal "decree" instead of an attack banner, a ticket-stub die-cut between photo and bio.

Light paper, not a dark card. First pass put this on a dark ink card stock, which clashed with the app's actual light Booth Ink theme — the rest of the game is never dark, so the card shouldn't invent a mode that doesn't exist elsewhere. Revised to the same warm-paper ground, thick ink border, and flat hard-shadow the app's own buttons already use.

The party color is the one variable. Everything else — paper, ink, brass, stamp-red — is fixed card stock, so the deck reads as one coherent set no matter who's on the card; only the masthead band and play button pick up each politician's real primaryColor.

What's real vs. placeholder. Portraits, colors, agendas, and the region-effect numbers on tap are pulled straight from politicians-data.json / policy-tags.json. The archetype line (e.g. "MASS MOBILIZER") is new flavor copy, one per politician, meant to double as a real read on how they play.
