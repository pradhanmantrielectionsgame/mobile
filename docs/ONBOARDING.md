# Onboarding Guide

Welcome to the Pradhan Mantri Elections Game project!

## Quickstart
1. Clone the repo and open in VS Code
2. Review `.github/copilot-instructions.md` and `docs/ARCHITECTURE.md`
3. Use PowerShell or VS Code terminal for commands
4. Run `python -m http.server` to test locally

## Key Files
- `js/`: Main game logic modules
- `data/`: Config and data files
- `assets/`: Images, icons, sounds
- `styles/`: CSS

## Workflow
- Follow the 6-step workflow in `.github/copilot-instructions.md`
- Use feature branches and PRs for all changes

## Common Pitfalls
- Not updating config or JSON for new features
- Breaking mobile/touch UI
- Exceeding 500 lines per JS file
