# Project Glossary

- **Phase System**: The timed sequence of game stages, managed by `phase-system.js`.
- **Ripple Effect**: System for propagating changes across states or players.
- **SVG Map ID**: The `id` attribute in the SVG map, must match `SvgId` in `states_data.json`.
- **Config Manager**: Central module for loading and distributing configuration and audio.
- **Dual-Player Input**: System supporting Player 1 (click) and Player 2 (Shift+Click).
- **State Manager**: Module handling state-specific data and map sync.
- **Debug Commands**: Console commands for testing and inspection (see `.github/copilot-instructions.md`).
